## ⭐ Featured Project

### Distributed Order Management System

A production-style distributed e-commerce platform built using Spring Boot microservices and Apache Kafka.

#### Key Concepts

* Saga Orchestration Pattern
* Event-Driven Architecture
* Distributed Transactions
* Compensation Workflows
* Dead Letter Queue (DLQ)
* Idempotent Event Processing
* Distributed Tracing
* Correlation IDs

#### Architecture Components

* Order Service
* Inventory Service
* Payment Service
* Saga Orchestrator
* Kafka Commands & Events
* PostgreSQL
* Docker

#### Engineering Challenges Solved

* Ensured transaction consistency across distributed services without relying on distributed database transactions.
* Designed compensation workflows for failure recovery and order rollback scenarios.
* Implemented idempotent consumers to prevent duplicate event processing.
* Added DLQ handling and retry mechanisms for failed Kafka messages.
* Implemented distributed tracing using correlation IDs and MDC logging.

## ⚙️ Local Development

Clone the repository:

```bash
git clone https://github.com/dbalmoor/deepana-portfolio.git
```

Navigate to the project:

```bash
cd portfolio-website
```

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```
